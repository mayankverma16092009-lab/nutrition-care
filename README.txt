NUTRITION CARE — STREAMLIT WEBSITE

Files:
  app.py           Main website application
  requirements.txt Python dependency

Run on a computer:
  1. Install Python 3.10 or newer.
  2. Open a terminal in this folder.
  3. Run: pip install -r requirements.txt
  4. Run: streamlit run app.py
  5. The website opens in your browser.

Deploy:
  You can deploy this project using Streamlit Community Cloud.
  Upload app.py and requirements.txt to a GitHub repository,
  then create a new app in Streamlit Community Cloud and select app.py.

IMPORTANT:
This is an educational nutrition project. The diet plan feature
selects general meal ideas from a small rule-based menu. It is not
a medical prescription, does not calculate nutrient requirements,
and should not be used to manage diabetes without a qualified
healthcare professional or registered dietitian.
